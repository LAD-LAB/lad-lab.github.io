# Gel Electrophoresis

After PCR, we run gel electrophoresis to confirm that the target amplicon was successfully amplified before proceeding to cleanup. For trnL products, we recommend increasing the agarose percentage or using an E-Gel 48 Agarose Gel (Thermo Fisher Scientific, Waltham, MA; Cat. No. G820804).

With amplification verified, proceed to [Amplicon Cleaning](cleaning.md).
